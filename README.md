# Faza Fahimatul 'Ilmiyah — Portfolio

Light-mode editorial portfolio built with React, TypeScript, Vite and Framer Motion.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

## Content & assets
- All text content lives in `src/data.ts`.
- Profile photo: `public/images/faza-profile.jpeg`
- Downloadable CV: `public/files/CV-Faza_Fahimatul_Ilmiyah.pdf`
- Project dashboard previews (`src/Previews.tsx`) are decorative illustrations with no real figures.
